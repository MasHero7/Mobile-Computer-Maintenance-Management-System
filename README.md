# Mobile-Computer-Maintenance-Management-System

## Overview

A web-based management system designed to organize and streamline mobile phone and computer maintenance operations, from device reception to repair completion and customer delivery.

The application helps maintenance shops manage customers, devices, repair workflows, user access, and operational reports through a centralized interface.

## Key Features

- **End-to-End Maintenance Workflow:** Manage the device lifecycle through receiving, maintenance, ready-for-delivery, and delivered stages.
- **Customer and Device Management:** Maintain customer and device records associated with maintenance operations.
- **User and Access Management:** Manage users, roles, and permissions to control access to system functionality.
- **Shop Data Separation:** Organize maintenance records by shop to support separate shop-level data access.
- **Reports and Excel Export:** Generate operational reports and export data to Excel for further analysis and record-keeping.
- **Multilingual Interface:** Support Arabic and English, including right-to-left (RTL) and left-to-right (LTR) interface layouts.
